Модуль 3 — Безопасность сервера

От портов и ОС до контейнеров и отчётности: комплексный аудит сервера и веб-сервера.

Прогресс модуля 0%

Nmap: порты и сервисы

SYN (-sS)

sudo nmap -sS 192.168.1.10

UDP (-sU)

sudo nmap -sU --top-ports 200 192.168.1.10

Aggressive (-A)

sudo nmap -A 192.168.1.10

Все порты (-p-)

sudo nmap -sS -p- 192.168.1.10

NSE: проверка EternalBlue

nmap -p 445 --script smb-vuln-ms17-010 192.168.1.10

Lynis: аудит ОС

1
Установите Lynis из репозитория CISOFY.
2
sudo lynis audit system — только чтение, безопасно.
3
Разберите: [OK], [WARNING], [SUGGESTION].
4
Логи: /var/log/lynis.log и /var/log/lynis-report.dat.
Lynis выдаёт Hardening Index от 0 до 100 — отличный индикатор для отслеживания улучшений.

OpenVAS (Greenbone)

Docker-развёртывание

mkdir -p ~/greenbone && cd ~/greenbone
curl -O -L https://greenbone.github.io/docs/latest/_static/docker-compose.yml
docker compose pull && docker compose up -d

Веб-интерфейс: HTTPS. Логин admin / admin.

Рабочий процесс

Credentials → Targets → Scan Configs → запуск → отчёт с CVE.

Требуется минимум 4 ГБ RAM (рекомендуется 8 ГБ).

Nuclei: шаблонные проверки

go install github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest
nuclei -target https://example.com -severity critical,high

Встраивается в CI одной командой. Тысячи шаблонов от сообщества.

Trivy: контейнеры

brew install aquasecurity/trivy/trivy
trivy image --severity HIGH,CRITICAL nginx:1.25
trivy image --exit-code 1 --severity CRITICAL myapp:latest

Сканирует CVE в пакетах ОС, зависимостях, секреты и IaC-мисконфигурации.

DefectDojo: управление находками

Импорт XML-отчётов ZAP, OpenVAS, Nuclei, Trivy. Дедупликация по CWE, автоматическое закрытие исправленного, SLA и владельцы.

docker run -v $(pwd):/zap/wrk/:rw ghcr.io/zaproxy/zaproxy:stable \
  zap-baseline.py -t https://staging.example.com -x zap.xml

OWASP WSTG и чек-лист веб-сервера

WSTG-CONF-01 (Network Infrastructure Configuration) — методологическая основа.

  • Проверить версии веб-сервера на CVE.
  • Удалить дефолтные страницы и примеры.
  • Отключить debug-режим и подробные ошибки.
  • Запретить листинг директорий.
  • Заголовки: CSP, HSTS, X-Content-Type-Options, X-Frame-Options.
  • Проверить TLS (SSL Labs, testssl.sh).
  • Админ-панели недоступны извне.
  • Сервер работает с минимальными привилегиями.
  • Логирование и мониторинг включены.
  • Контейнеры просканированы Trivy — нет CRITICAL.

Полный цикл аудита

1
Nmap: инвентаризация хостов и портов.
2
Lynis: аудит ОС.
3
OpenVAS + Nuclei: поиск CVE.
4
ZAP: baseline + full scan веб-приложения.
5
Trivy: образы и файловые системы.
6
DefectDojo: централизация, дедупликация, SLA.
7
Исправление и повторный скан.
