Прогресс модуля 0%

Fuzzer: перебор полезных нагрузок

Fuzzer автоматически отправляет множество вариантов запроса с разными значениями параметра. Правый клик по запросу → Attack → Fuzz…, выберите параметр и payload'ы (SQLi, XSS, directory traversal).

Фаззинг генерирует много трафика. Не применяйте к production без разрешения.

Скрипты и расширения

ZAP поддерживает JavaScript (GraalVM), Zest, Python (Jython), Groovy, Kotlin, Ruby.

HTTP Sender

Выполняется для каждого запроса/ответа. Идеален для добавления заголовков и логирования.

Active Rules

Собственные правила Active Scan под специфику вашего приложения.

Аутентификация и сессии

1
Контекст. Определяет границы приложения и исключения (например, logout).
2
Метод. Form-based, JSON, HTTP/NTLM, Script, Browser-based.
3
Индикаторы. Regex или текст, по которому ZAP понимает «вошёл/вышел».
Аутентифицированные сканы находят в 3–5 раз больше проблем, чем анонимные.

AJAX Spider и HUD

AJAX Spider запускает реальный браузер — обходит SPA на React/Angular/Vue. HUD встраивает элементы управления ZAP прямо в браузер.

Broken Access Control и SSRF

IDOR

/api/user/123/profile → измените 123 на 124. Если видите чужой профиль — уязвимость.

SSRF

Приложение принимает URL и делает запрос от имени сервера. Пример: http://169.254.169.254/ в облаке.

Защита: allowlist доменов/IP, запрет редиректов.

Небезопасная десериализация

Приложение десериализует данные от пользователя без проверки → внедрение вредоносного объекта. Относится к A08: Software and Data Integrity Failures.

Пример: Java-приложение принимает сериализованный объект в cookie. Инструмент ysoserial создаёт payload, выполняющий команду на сервере.
